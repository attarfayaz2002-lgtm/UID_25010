Title: Myntra-Inspired Fashion Web Application
A responsive fashion shopping landing page built with HTML, CSS, and JavaScript.  The project is inspired by modern e-commerce platforms like Myntra and focuses on clean UI design, product discovery, category navigation, and interactive shopping features.

Project Overview:
This website presents a stylish online fashion store interface where users can explore clothing, beauty, home, and Genz collections from a single-page layout. The design includes a sticky navigation bar, promotional hero section, category cards, dynamic product cards, search functionality, login popup, cart counter, and informative footer sections.

The main goal of this project is to demonstrate practical front-end development skills through a visually appealing and interactive e-commerce website.

 Features

- Responsive Myntra-style homepage design
- Dynamic product rendering using JavaScript
- Category filtering for Men, Women, Kids, Home, Beauty, and GenZ
- Real-time search for products, categories, page sections, and footer links
- Demo login modal with basic validation message
- Add-to-bag button with live cart count update
- Interactive footer links with detailed policy and support information
- Smooth scrolling for better navigation
- Mobile-friendly layout using CSS media queries


 Tech Stack:

HTML5 - Page structure and content
CSS - Styling, layout, responsiveness, and visual design
JavaScript- Product rendering, filtering, search, modal, and cart interactions
Font Awesome - Icons for search, profile, wish list, and bag
Google Fonts - Assistant font for a polished shopping interface
